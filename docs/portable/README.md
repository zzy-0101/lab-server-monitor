# 服务器监控：Mac / Windows 迁移说明

这个文件夹就是监控程序。先完整解压ZIP，再复制整个文件夹到新电脑；只复制一个.command或.bat文件不能运行。目标服务器仍为Linux，监控电脑可以使用macOS或Windows。

详细图文步骤见包内 **`使用说明.pdf`**。本项目源码中的对应文档位于`docs/guide/服务器监控入门指南.pdf`。

## macOS

1. 安装/确认Python 3.9或更新版本，并能在终端执行`python3 --version`和`ssh -V`。
2. 双击`Start-Mac.command`，会在默认浏览器打开本机GUI。
3. 如果文件没有执行权限，在此文件夹打开终端运行：

```bash
chmod +x Start-Mac.command
./Start-Mac.command
```

也可以直接运行：

```bash
python3 tools/launch_monitor.py
```

macOS使用系统OpenSSH，不需要安装额外的Python包。

## Windows

1. 安装/确认Python 3.9或更新版本，命令行中`python --version`或`py -3 --version`应能运行。
2. **首次使用**，双击`Install-Windows.bat`。它在当前文件夹创建`.venv`虚拟环境，并联网安装Paramiko及依赖，不需要修改系统Python或使用管理员权限。
3. **以后使用**，双击`Start-Windows.bat`。它优先使用当前文件夹的虚拟环境，打开相同的浏览器GUI。
4. 如果电脑上已有Paramiko，可跳过安装脚本，直接运行启动脚本或`python tools/launch_monitor.py`。

Windows使用Paramiko直接建立SSH连接，无需另装OpenSSH客户端、WSL或Git Bash。Python包通过pip安装的方式见[Paramiko官方说明](https://www.paramiko.org/installing.html)。

安装失败时保留窗口中的错误提示；安装依赖需要互联网。不要复制其他操作系统的`.venv`文件夹，到新电脑重新安装依赖。

## 新电脑首次连接

- 电脑需要能访问服务器所在内网，或已经连接相应VPN。
- 首次打开会列出 7 台预设服务器的地址和端口，初始用户名为 `your_username`，监控默认停用。可以修改这些连接，也可以自行添加服务器。
- 点击服务器卡片的齿轮，填写自己的用户名，认证方式选“密码”，填写密码，按需要勾选“记住用户名”“记住密码”和“启用此服务器的监控”，再点“保存并连接”。其他服务器分别设置；新增连接使用“添加服务器”。
- “记住用户名”默认勾选；同时勾选“记住密码”后，后续启动会自动连接。密码保存在本机 Mac 钥匙串或 Windows 凭据管理器中。取消记住密码后仅本次有效；取消记住用户名后，下次需要重新填写账号。
- 要使用免密登录，请选择**新电脑上的**私钥文件，并确保对应公钥已加入远端账号的`authorized_keys`。原电脑的免密设置不会自动出现在新电脑上。
- 密钥文件路径与用户名都是本机/账号相关的；不要照搬原电脑的`/Users/...`绝对路径。Windows可填写`C:\Users\你的名字\.ssh\id_ed25519`。
- “我的进程”显示各服务器当前登录账号的进程；“全部进程”显示该账号有权限读取的全部用户进程。使用其他账号时，相应修改用户名和凭据。
- 首次连接会在新电脑的`~/.ssh/known_hosts`记录服务器密钥；后续密钥变更将阻止连接，需先向管理员核实。

## 日常操作

- 顶部卡片显示CPU空闲率、等效空闲逻辑核、可用内存、负载和最近更新时间。
- 可同时监控多台，按5/10/30/60秒刷新；数据在原位替换。单台连接慢或失败不阻塞其他服务器。
- “磁盘与挂载”表格显示挂载路径、设备/文件系统、总容量、已用/可用容量、使用率和挂载模式；单位GiB，可按服务器或路径筛选。可用空间不含保留块，同一文件系统的不同挂载路径不重复相加。
- 右上角添加服务器；卡片齿轮编辑IP、端口、用户名、密码或密钥。可暂停、启用/停用、移除监控项。
- “运行中的进程”统计状态为 R 或采样期间有 CPU 占用的进程。进程表格默认筛选这些活跃进程，可切换全部状态、运行中、休眠、I/O 等待、已停止和僵尸进程；排序与搜索会保留状态筛选。支持按服务器筛选、分页，点击行查看完整命令与工作目录。
- 只关闭浏览器标签页不会退出本地服务；点击左下角“退出程序”停止监控，服务器上的计算任务继续运行。
- 非敏感连接配置保存到`lab_servers/gui_config.json`；密码不会写入其中。需要干净迁移时，只使用原始ZIP，不带上已有配置和`*.runtime.json`。

## 兼容性与验证范围

macOS已进行真实服务器连接和GUI验收；Windows启动入口和独立SSH后端已补齐，后端在Mac上进行了测试。本次没有Windows实体机或Windows虚拟机，尚未完成真实Windows系统的端到端验收。

本工具需要远端 Linux 的 `/proc` 和 Python 3.6+。远端解释器不在默认路径时，在连接窗口的“更多设置”中填写其完整路径。
